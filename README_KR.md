## 🚀 주요 프로젝트

### ☁️ Cloud Management Platform

사용자가 필요한 환경을 요청하면
VM 생성부터 소프트웨어 설치까지 자동으로 수행하는
**Cloud Management Platform 프로토타입**을 구축했습니다.

**주요 기술**

`VMware vSphere` · `Ansible` · `Jenkins` · `Terraform` · `Prometheus` · `Grafana`

**주요 구현 내용**

* VM Provisioning 자동화
* Gold Image 기반 VM 생성
* Ansible 기반 소프트웨어 설치 및 환경 구성
* Gateway / Reverse Proxy 기반 네트워크 구조
* Jenkins 기반 CI/CD Pipeline
* Prometheus & Grafana 기반 인프라 모니터링
* Management / Workload 영역 분리
* 사용자별 인프라 리소스 관리
